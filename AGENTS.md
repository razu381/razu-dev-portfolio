# Project Rules

## Git Push Policy
- After completing a **plan implementation** (multi-step planned changes), automatically stage, commit with a descriptive message, and push to the remote.
- For regular edits, bug fixes, or small changes — do NOT push unless explicitly asked.
- Only commit when explicitly asked OR when finishing a plan implementation.

## Build Verification
- Always run `npx next build` after making changes to verify no errors before committing.
